# Private research data: not included in public GitHub

Place real raw Excel workbooks, final MATLAB v7.3 `.mat` posterior and PPC files,
and archived feature CSVs in this folder **locally or in a private Codespace**.
The `.gitignore` excludes their contents; verify with `git status` before push.
Do not put unpublished Excel, research posteriors, growth data or plate maps in a public repository or public Binder environment.
